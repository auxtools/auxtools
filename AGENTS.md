# Design notes

`docs/design/` contains reference notes recording what auxtools does that is not obvious from its
code and why: design decisions, how internal mechanisms work, and facts about BYOND or DreamMaker
found by experiment that the code depends on.

- `docs/design/README.md` indexes the notes by area and title.
- `docs/design/by-file.md` indexes the notes by source file, listing the notes that apply to each
  file (and the items they name in it) under a heading with the file's path.
