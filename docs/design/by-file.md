# Design notes by source file

This index maps source files to the design notes that cover them, so anyone changing a file can
find the relevant notes in one place. For the main index organized by area and title, see
[README.md](README.md).

Entries are grouped under a `##` heading per top-level directory, with a `###` heading for each
file's repository-relative path (files in the repository root get their own `##` heading). Each
bullet links to a note by title and lists any items that note names in that file.

Everything from the first `##` heading onward is generated by `ci/design-notes.py` from the notes'
`## Applies to` lists and should not be edited by hand. Run `ci/design-notes.py` to regenerate this
file after adding a note or changing an `## Applies to` list.
